# Pré-processamento de Dados para Análise de Churn em Telecom 

Este repositório apresenta um projeto focado na etapa de pré-processamento e análise exploratória de dados, aplicado a um problema de churn de clientes no setor de telecomunicações.

O objetivo principal foi preparar a base de dados para análises e futuras etapas de modelagem, garantindo qualidade, consistência e padronização de informações.
---


## 🔹 Etapa 1 — Pré-processamento e Tratamento dos Dados

Nesta etapa foram realizadas as seguintes atividades:

- Carregamento da base de dados
- Verificação e correção dos tipos de dados
- Tratamento de valores ausentes
- Padronização de variáveis categóricas
- Identificação e análise de possíveis outliers
- Geração de um dataset tratado para uso posterior

O arquivo `churn_tratado_m14.csv` representa o resultado final do pré-processamento dos dados.

---

## 🔹 Etapa 2 — Análise Exploratória com Base nos Dados Tratados

Após o pré-processamento, foi realizada uma análise exploratória inicial utilizando o dataset tratado, com foco na variável **churn**, incluindo:

- Análise univariada das principais variáveis
- Análise bivariada
- Criação de visualizações gráficas para facilitar a interpretação dos dados
- Extração de insights iniciais sobre o comportamento dos clientes

Essa etapa ajuda a entender melhor os dados e preparar o terreno para futuras análises e modelos preditivos.

---

## 🛠️ Tecnologias Utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 🎯 Objetivo do Projeto

Demonstrar a importância do **pré-processamento de dados** em projetos de ciência de dados, preparando uma base consistente e confiável para análises e modelagem preditiva de churn.
