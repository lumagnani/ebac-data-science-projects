# Projeto — Fundamentos da Descoberta de Dados

Este projeto foi desenvolvido como parte do módulo Estatística Básica do curso de Ciência de Dados da EBAC. O objetivo foi praticar os primeiros passos da análise exploratória de dados (EDA), incluindo limpeza, padronização e visualização de dados utilizando Python.

O notebook apresenta o processo de análise de forma sequencial, com explicações ao longo do código para facilitar o entendimento das etapas e das decisões tomadas durante a exploração dos dados.

---

## Tecnologias e bibliotecas utilizadas

- Python  
- Pandas  
- Matplotlib  
- Plotly  
- Jupyter Notebook  

---

## 📁 Conjunto de dados

O dataset utilizado contém informações de produtos de supermercado, incluindo preços, categorias, marcas e descontos.

---

## Etapas do projeto

### 1. Importação e configuração do ambiente
- Importação das bibliotecas necessárias
- Configuração de estilo dos gráficos
- Leitura do arquivo CSV

---

### 2. Análise inicial dos dados
- Visualização das primeiras linhas do dataset
- Verificação de tipos de dados
- Cálculo de estatísticas descritivas para variáveis numéricas e categóricas

---

### 3. Limpeza e padronização
- Padronização dos nomes das colunas (minúsculas e underscores)
- Conversão de colunas de preço e desconto para formato numérico
- Verificação de valores ausentes

---

## Exercícios desenvolvidos

### Exercício 1 — Média e mediana do preço normal por categoria
- Agrupamento por categoria
- Cálculo de média, mediana e quantidade de produtos
- Comparação entre categorias com média acima ou abaixo da mediana

---

### Exercício 2 — Desvio padrão por categoria
- Cálculo do desvio padrão do preço normal
- Identificação da categoria com maior variabilidade de preços

---

### Exercício 3 — Boxplot do preço normal
- Criação de boxplot para a categoria com maior desvio padrão
- Análise de dispersão e possíveis outliers

---

### Exercício 4 — Média de desconto por categoria
- Criação de gráfico de barras com a média de desconto por categoria
- Comparação visual entre categorias

---

### Exercício 5 — Gráfico interativo por categoria e marca
- Agrupamento por categoria e marca
- Cálculo da média de desconto
- Visualização interativa utilizando Plotly

---

## Principais aprendizados

- A importância da limpeza e padronização dos dados antes das análises
- Como utilizar estatísticas descritivas para entender a distribuição das variáveis
- Escolha de diferentes tipos de gráficos conforme o objetivo da análise
- Uso de visualizações interativas para explorar dados categóricos
