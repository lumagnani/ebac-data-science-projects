# Rental Price Regression Analysis

Projeto de análise e modelagem preditiva para estimar valores de aluguel utilizando regressão linear simples e múltipla.

## Tecnologias utilizadas
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn

## Etapas do projeto
- Limpeza de dados
- Tratamento de outliers
- Análise de correlação
- Regressão linear simples
- Regressão linear múltipla
- Avaliação com R²

## Resultados

### Regressão simples
R² treino: 0.33  
R² teste: 0.35  

### Regressão múltipla
R² treino: 0.417  
R² teste: 0.436  

## Principais insights
O modelo de regressão múltipla apresentou melhor desempenho por considerar múltiplas variáveis relevantes para previsão do valor do aluguel.
