# EBAC Data Science Projects

Repositório com projetos desenvolvidos durante minha formação em Ciência de Dados na EBAC (Escola Britânica de Artes Criativas e Tecnologia).

Este repositório reúne exercícios práticos, análises exploratórias e projetos de machine learning desenvolvidos ao longo da formação.

## Projetos

### 01 - Calculadora Simples
Projeto introdutório com lógica de programação em Python.

### 02 - Análise de Dados de Mercado
Análise exploratória de dados utilizando Python e bibliotecas de manipulação de dados.

### 03 - Visualização de Dados Ecommerce
Projeto focado em visualização de dados e geração de insights de negócio.

### 04 - Análise de Churn
Análise de evasão de clientes e identificação de padrões de cancelamento.

### 05 - Regressão de Aluguel
Projeto de regressão linear simples e múltipla para previsão de valores de aluguel.

**Resultados principais:**
- Regressão simples → R² teste: 0.35
- Regressão múltipla → R² teste: 0.436
