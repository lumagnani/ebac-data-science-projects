# 🧮 Calculadora em Python (Terminal)

Este projeto é uma **calculadora simples em Python**, executada no terminal, que permite realizar operações matemáticas básicas entre dois números informados pelo usuário.

O programa funciona em loop, permitindo realizar várias operações até que o usuário escolha sair.

---

## 🚀 Funcionalidades

- Soma (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)
  - Tratamento de erro para divisão por zero
- Menu interativo no terminal
- Execução contínua até o usuário encerrar o programa

---

## 🛠️ Tecnologias utilizadas

- **Python 3**
- Estruturas básicas:
  - `while`
  - `if / elif / else`
  - `input()`
  - `print()`
